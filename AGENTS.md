# AGENTS.md

* Run in virtual environment with `conda run -n capymoa ...`.
* Run doctests with `conda run -n capymoa pytest --doctest-modules src`.
* Run unit tests with `conda run -n capymoa pytest tests`.
* Build documentation with `conda run -n capymoa invoke docs`. Recommend grepping for errors.
* Clean documentation with `conda run -n capymoa invoke docs.clean`.
